# DemGram — کلاینت قدرتمند تلگرام + سلف گولاخ

**DemGram** کلاینت تلگرام با 1000 قابلیت است که تمام ویژگی‌های سلف ترموکس را داخل خود دارد.

## ویژگی‌های کلیدی (خلاصه)

- **چند اکانت نامحدود**: هر سشن جدا، `account.session`, `my2.session`
- **مدیریت مخاطبین هوشمند**:
  - `.contacts [عبارت]` لیست ۵۰ تایی با فیلتر
  - `.filter اسم` / `.find @username` جستجو
  - `.add @username` افزودن تکی امن (ریپلای هم می‌شه)
  - `.addall confirm` → `.addall YES` افزودن همه با تایید دوم و تاخیر ۳ ثانیه‌ای، سقف ۵۰ تا ضداسپم
  - `.addselect` انتخاب خاص
- **مدیریت گروه**: `.stats`, `.admins`, `.invite`, `.pin`, `.unpin`
- **متن خفن**: `.font متن` ۷ استایل + `.bold`, `.italic`, `.code`, `.reverse`
- **هوش مصنوعی**:
  - `.ai سوال` محلی context-aware
  - اگر `OPENAI_API_KEY` محلی ست کنی، از دستگاه خودت مستقیم به OpenAI می‌زنه (کلید هرگز به سرور نمی‌ره)
  - `.tr متن` ترجمه
- **چت‌بات سلف**: `.chat on/off` ۵٪ پیام‌ها خودکار
- **امنیت**: هیچ ارسال انبوه بدون تایید، نشست فقط محلی، کلید فقط محلی، تایید YES، سقف ۵۰، تاخیر ضدفlood

## نسخه‌ها

1. **وب PWA** (`/demgram/`): قابل نصب به عنوان APK via Add to Home Screen، تمام فیچرها داخل مرورگر، داده فقط در localStorage
2. **ترموکس سلف** (`termux/self_client.py`): پایتون با Telethon، چند سشن
3. **اندروید بومی** (`demgram/android/`): اسکلت Kotlin + WebView که PWA را لود می‌کند + TDLib اختیاری + نوتیفیکیشن بومی + مخاطبین گوشی

## دانلود از ربات

داخل پیوی ربات نوا:
```
demgram
کلاینت
دانلود
```
یا دکمه "دانلود DemGram" در پنل.

لینک مستقیم وب:
- `/demgram/` — کلاینت وب
- `/demgram/FEATURES.html` — لیست 1000 قابلیت

## نصب APK (روش PWA)

1. برو به `/demgram/` با کروم اندروید
2. منو → Add to Home Screen / نصب برنامه
3. حالا مثل APK بومی کار می‌کند

برای APK واقعی:
```bash
cd demgram/android
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## امنیت

- نشست MTProto هرگز آپلود نمی‌شود
- API ID/HASH فقط محلی
- کلید OpenAI فقط محلی
- افزودن انبوه با تایید YES و تاخیر ۳ ثانیه‌ای
- سقف ۵۰ برای جلوگیری از بن تلگرام
- هیچ جمع‌آوری عضو از گروه دیگران بدون اجازه
