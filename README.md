# ✦ نُوا گارد — NOVA GUARD — اپ جدا، بات جدا، سلف جدا، یه ورکر

**بات جدا، اپ جدا، سلف جدا ولی با یه ورکر ران میشه.**

- **اپ به ربات وصله:** از پیوی ربات `demgram` / `دانلود` / `اپ` بزن → لینک دانلود APK + وب PWA
- **سلف به ربات وصله:** از پیوی ربات `سلف` بزن → کد ۳۲ کاراکتری → داخل `self/self_client.py` وارد کن

## معماری جدید — سه چیز جدا

```
[بات] ←→ ورکر ←→ [اپ] 
[سلف] ←→ ورکر
```

- **بات:** مدیریت گروه تلگرام — 140 دستور، پنل اینلاین، قفل همه، دوئل تاس واقعی، ضداسپم، خوشامد، etc — روی ورکر ران میشه
- **سلف جدا:** حساب شخصی خودت — 60+ دستور، مدیریت مخاطبین هوشمند .contacts .filter .add .addall confirm→YES با تاخیر ۳ثانیه سقف ۵۰، دانلودر، کانفیگ ساز خفن VLESS/VMess/SS/Trojan/پروکسی — فقط از بات فعال میشه، نشست فقط روی دستگاه خودت
- **اپ DemGram جدا:** کلاینت تلگرام + دانلودر یوتیوب/اینستا/تیک‌تاک بدون واترمارک + کانفیگ ساز خفن + پروکسی MTProto + فونت ساز — از بات دانلود میشه، با یه ورکر ران میشه (PWA + APK بومی)

## نصب روی کلودفلر — یه ورکر برای هر سه

1. دکمه **Deploy to Cloudflare** بالا → فقط `PANEL_PASSWORD` (حداقل ۱۶ کاراکتر) بده
2. Deploy تمام → آدرس ورکر خودت رو باز کن، با رمز وارد شو
3. توکن ربات رو از BotFather بگیر، داخل پنل ثبت کن → اتصال خودکار، وبهوک، منوی دستورها
4. بات رو به گروه اضافه کن، ادمین کن، `پنل` بفرست

## بات — 140 دستور

- مدیریت: پنل اینلاین، قفل لینک/استیکر/..., قفل همه ۲۴ فیلتر، ضداسپم، کپچا، ضدهجوم، حالت شب
- اقتصاد: سکه، الماس کمیاب، روزانه، لیدربرد، دوئل تاس واقعی 🎲 (غیرقابل تقلب سمت سرور)
- ابزار: فونت ساز ۷ استایل، حساب، دانلودر، کانفیگ ساز
- دانلودر: `دانلود https://youtube.com/...` یا `dl` — یوتیوب/اینستا/تیک‌تاک/توییتر
- کانفیگ ساز: `کانفیگ example.com` → VLESS/VMess/SS/Trojan + ساب لینک، `پروکسی` → لیست MTProto، `ساب` → ساب لینک ساز

فهرست کامل: `docs/FEATURES.fa.md`

## سلف جدا — 60+ دستور — فقط از بات فعال میشه

```bash
pip install -r self/requirements.txt

# اکانت اول
python self/self_client.py

# اکانت دوم نامحدود
python self/self_client.py --session my2

# فقط توکن عوض شود
python self/self_client.py --pair
```

**قابلیت‌ها:**
- `.contacts [فیلتر]` لیست ۵۰ تایی، `.filter نام`، `.find @username`
- `.add @username` تکی امن، `.addall confirm` → `.addall YES` با تاخیر ۳ثانیه ضداسپم سقف ۵۰
- `.stats .admins .invite .pin .kick .ban .mute .tagall`
- `.font متن` ۷ استایل، `.dl لینک` دانلودر، `.config` کانفیگ ساز خفن، `.vless .vmess .ss .trojan .proxy .sub`
- `.ai سوال` هوش مصنوعی محلی/ابری (کلید فقط محلی)

**اتصال:** پیوی ربات `سلف` → کد ۳۲ کاراکتری → داخل سلف وارد کن — نشست فقط روی دستگاه خودت میمونه

## اپ DemGram جدا — دانلودر + کانفیگ ساز خفن

**اپ کاملا جدا از سلف و بات، ولی با یه ورکر ران میشه و از بات دانلود میشه.**

### قابلیت‌ها:

**📥 دانلودر:**
- یوتیوب (ویدیو/صدا MP3/MP4)
- اینستاگرام (پست/استوری/ریلز)
- تیک‌تاک بدون واترمارک
- توییتر/X
- تلگرام فایل بزرگ
- دانلود منیجر

**🔐 کانفیگ ساز خفن:**
- VLESS با Reality
- VMess
- Shadowsocks
- Trojan
- ساب لینک ساز (subscription) base64
- پروکسی MTProto — لیست، تست سرعت، ساخت
- QR کد برای کانفیگ‌ها
- وارد کردن از کلیپ‌بورد

**👥 تلگرام کلاینت:**
- چند اکانت نامحدود
- مدیریت مخاطبین هوشمند
- مدیریت گروه

### نصب اپ:

**PWA (فوری):**
1. `/demgram/` با کروم اندروید باز کن
2. منو → Add to Home Screen / نصب برنامه
3. حالا مثل APK بومی توی لیست برنامه‌ها میاد

**APK بومی:**
- از ربات: پیوی ربات `demgram` / `دانلود` / `اپ` → لینک `/demgram/DemGram.apk`
- یا بیلد: `cd app/android && ./gradlew assembleDebug`

### لینک‌های اپ:
- وب PWA: `/demgram/`
- APK مستقیم: `/demgram/DemGram.apk`
- ۱۰۰۰ قابلیت: `/demgram/FEATURES.html`
- API دانلودر: `/api/download`
- API کانفیگ: `/api/config/generate`
- API پروکسی: `/api/proxy/list`
