# ⚡ AMINCK Nova Bot

ربات حرفه‌ای فروش کانفیگ روی **Cloudflare Workers** — کاملاً سرورلس با **D1 + KV**؛ مدیریت کامل **داخل خود تلگرام**.

> 🤖 فروشگاه خودکار، پنل مدیریت شیشه‌ای، رفرال، مینی‌اپ سکه‌ای، چت هوش مصنوعی، QR برند، تایید فیش با هوش مصنوعی، تبلیغ گروه‌ها و یادآوری تمدید — همه در یک ورکر.

---

## ✨ امکانات

| بخش | جزئیات |
|---|---|
| 👑 **سوپرادمین خودکار** | اولین کاربری که `/start` بزند، سوپرادمین می‌شود؛ دکمه «📊 پنل مدیریت» فقط برای ادمین‌ها |
| 📊 **پنل مدیریت** | آمار روز/هفته/ماه، صف فیش‌ها با تایید/رد سریع، مدیریت محصولات/سرورها/کاربران/ادمین‌ها/گروه‌ها، تنظیمات کامل، خروجی CSV/JSON — همه با دکمه‌های شیشه‌ای و ادیت پیام |
| 🛍 **فروشگاه** | VLESS / V2ray / Trojan / Shadowsocks / OpenVPN / MTProto / SOCKS5 + کانفیگ‌ساز اختصاصی (ویژه) |
| 💳 **پرداخت** | کارت‌به‌کارت + بررسی هوشمند فیش (بینایی Groq: مبلغ/تاریخ/ساعت/دستکاری) — مشکوک به صف ادمین، معتبر تایید خودکار؛ کیف پول و شارژ |
| 👥 **رفرال** | لینک اختصاصی `t.me/bot?start=ref_ID`، ۱۰٪ نقدی بعد اولین خرید زیرمجموعه، کانفیگ رایگان با ۵ دعوت |
| 🎁 **تست رایگان** | یک‌بار برای هر کاربر: ۱ روزه، ۵۰ مگ، پرسرعت‌ترین سرور؛ انقضای خودکار |
| 🔗 **ساب چندکانفیگه** | ~۱۰ سرور در هر ساب + کرون سلامت سرورها و جایگزینی خودکار سرور مرده |
| 🔳 **QR برند** | رنگ برندی سرمه‌ای/طلایی + لوگوی سکه وسط + فریم (کاملاً سرورلس، PNG داخلی) |
| 🎮 **مینی‌اپ سکه‌ای** | تپ با انیمیشن، سطوح Bronze/Silver/Gold/Diamond، آپگرید انرژی/سرعت، چرخ شانس روزانه، لیگ هفتگی با جایزه، ماموریت‌های روزانه، فروشگاه سکه‌ای |
| 🤖 **چت هوش مصنوعی** | ۵ سکه هر پیام، تاریخچه کوتاه، از Groq |
| 📢 **گروه‌ها** | ثبت خودکار گروه‌ها، خوش‌آمد عضو جدید، پست تبلیغی زمان‌بندی‌شده با نرخ لحظه‌ای و دکمه «🛒 خرید در پیوی»، پست فوری دستی |
| ⏰ **یادآوری** | یادآوری قبل از انقضا + دکمه تمدید سریع + تخفیف کاربر غیرفعال |
| 💵 **قیمت‌گذاری هوشمند** | نرخ دلار از API هر چند ساعت + کش KV ۱۵ دقیقه‌ای + مارجین قابل‌تنظیم + نرخ دستی |

## 🚀 دیپلوی (۵ دقیقه)

### ۱) پیش‌نیاز

```bash
git clone https://github.com/amingangmanatgh2-hash/AMINCK-Nova-Edge.git
cd AMINCK-Nova-Edge
npm install
npx wrangler login        # ورود به حساب کلادفلر
```

### ۲) ساخت خودکار KV و D1

```bash
npm run setup
```

این اسکریپت `KV` و دیتابیس `nova-bot-db` را می‌سازد و آیدی‌ها را در `wrangler.toml` می‌نویسد.

### ۳) سکرت‌ها

```bash
echo "توکن_بات_شما" | npx wrangler secret put TELEGRAM_BOT_TOKEN
echo "gsk_..." | npx wrangler secret put GROQ_API_KEY      # اختیاری: چت AI + تایید هوشمند فیش
```

### ۴) دیپلوی

```bash
npm run deploy
```

### ۵) تنظیم آدرس ورکر

خروجی دیپلوی آدرسی مثل `https://aminck-nova-bot.USER.workers.dev` می‌دهد. آن را در `wrangler.toml` جلوی `WORKER_URL` بگذارید و دوباره دیپلوی کنید:

```bash
npm run deploy
```

> این آدرس برای لینک ساب، صفحه لندینگ، مینی‌اپ و QR لازم است.

### ۶) داده نمونه (اختیاری)

```bash
npx wrangler d1 execute nova-bot-db --remote --file scripts/seed.sql
```

حالا ربات را در تلگرام `/start` کنید: **اولین کاربر، سوپرادمین است** و پروفایل بات (نام، توضیحات، دستورها، عکس) به‌صورت خودکار ست می‌شود. از دکمه «📊 پنل مدیریت» محصولات و سرورهای واقعی‌تان را ثبت کنید.

### توسعه محلی

```bash
cp .dev.vars.example .dev.vars    # توکن را داخلش بگذارید
npm run dev
```

## 🔐 امنیت توکن

توکن بات را **هرگز** در کد یا `wrangler.toml` نگذارید؛ فقط با `wrangler secret put` ثبت کنید. اگر توکن فعلی در جایی عمومی شده، از BotFather توکن جدید بگیرید و سکرت را جایگزین کنید.

کلید Groq رایگان: [console.groq.com](https://console.groq.com) → API Keys.

## 🗂 ساختار

```
src/
├── index.js      # ورکر، وب‌هوک، خود-راه‌اندازی پروفایل بات، مسیرهای وب
├── db.js         # اسکیما D1 + ساعد‌ها + «اولین کاربر = سوپرادمین»
├── tg.js         # کلاینت Bot API + کیبوردها
├── texts.js      # متن‌های فارسی قابل‌ویرایش از پنل
├── user.js       # منو، فروشگاه، حساب، رفرال، تست، پشتیبانی، چت AI
├── admin.js      # پنل مدیریت کامل با سطوح دسترسی
├── pay.js        # سفارش/کیف‌پول/کارت/تحویل/پاداش رفرال
├── verify.js     # بررسی فیش با بینایی Groq
├── subs.js       # ساب چندکانفیگه + جایگزینی سرور مرده + لندینگ
├── qr.js         # QR برند (انکودر PNG سرورلس)
├── game.js       # API و صفحه مینی‌اپ سکه‌ای (WebApp)
├── group.js      # خوش‌آمد گروه + پست تبلیغ زمان‌بندی‌شده
├── jobs.js       # کرون: نرخ ارز، سلامت سرور، یادآوری، لیگ
├── pricing.js    # نرخ لحظه‌ای + مارجین + کش KV
└── logo.js       # لوگوی بات (بیس۶۴)
scripts/
├── setup.mjs     # ساخت خودکار KV/D1
└── seed.sql      # محصولات و سرورهای نمونه
```

## ⚙️ متغیرها (Secrets/Vars)

| نام | نوع | توضیح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | secret | **الزامی** — توکن ربات |
| `GROQ_API_KEY` | secret | اختیاری — چت AI و بررسی فیش |
| `WORKER_URL` | var | آدرس عمومی ورکر (بعد از دیپلوی) |
