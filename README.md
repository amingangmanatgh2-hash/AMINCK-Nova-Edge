# ⚡ AMINCK Nova Bot

ربات حرفه‌ای فروش کانفیگ روی **Cloudflare Workers** — کاملاً سرورلس؛ مدیریت کامل **داخل خود تلگرام**.
دیتابیس داخل **Durable Object (SQLite)** است؛ یعنی دیپلوی با **یک کلیک** و بدون ساخت هیچ کلید KV/D1.

> 🤖 فروشگاه خودکار، پنل مدیریت شیشه‌ای، رفرال، مینی‌اپ سکه‌ای، چت هوش مصنوعی، QR برند، تایید فیش با هوش مصنوعی، تبلیغ گروه‌ها و یادآوری تمدید — همه در یک ورکر.

---

## 🚀 دیپلوی با یک کلیک

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/amingangmanatgh2-hash/AMINCK-Nova-Edge)

1. روی دکمه بالا بزنید → به گیت‌هاب و کلادفلر وصل شوید → **Deploy**
2. تمام! هیچ KV/D1/کلیدی لازم نیست؛ دیتابیس خودکار ساخته می‌شود و **توکن بات داخل کانفیگ دیپلوی است**.
3. در تلگرام `/start` بزنید — **اولین کاربر سوپرادمین** است و پروفایل بات (نام، توضیحات، دستورها، عکس) خودکار تنظیم می‌شود.

> ℹ️ آدرس ورکر به‌صورت خودکار ذخیره می‌شود (لینک ساب، QR و مینی‌اپ بدون تنظیم اضافی کار می‌کنند).
> برای امنیت بیشتر می‌توانید بعداً توکن را از `wrangler.toml` حذف و با `npx wrangler secret put TELEGRAM_BOT_TOKEN` به‌صورت Secret ثبت کنید.

### دیپلوی دستی (اختیاری)

```bash
npm install
npx wrangler login
npm run setup     # = wrangler deploy
```

### توسعه محلی

```bash
cp .dev.vars.example .dev.vars
npm run dev
```

## ✨ امکانات

| بخش | جزئیات |
|---|---|
| 👑 **سوپرادمین خودکار** | اولین `/start` = سوپرادمین؛ دکمه «📊 پنل مدیریت» فقط برای ادمین‌ها |
| 📊 **پنل مدیریت** | آمار روز/هفته/ماه، صف فیش‌ها با تایید/رد سریع، محصولات/سرورها/کاربران/ادمین‌ها با سطح دسترسی/گروه‌ها/تنظیمات/خروجی CSV و JSON — با دکمه‌های شیشه‌ای و ادیت پیام |
| 🛍 **فروشگاه** | VLESS / V2ray / Trojan / Shadowsocks / OpenVPN / MTProto / SOCKS5 + کانفیگ‌ساز اختصاصی (ویژه) |
| 💳 **پرداخت** | کارت‌به‌کارت + بررسی هوشمند فیش (بینایی Groq: مبلغ/تاریخ/ساعت/دستکاری) — مشکوک به صف ادمین، معتبر تایید خودکار؛ کیف پول و شارژ |
| 👥 **رفرال** | لینک `t.me/bot?start=ref_ID`، ۱۰٪ نقدی بعد اولین خرید زیرمجموعه، کانفیگ رایگان با ۵ دعوت |
| 🎁 **تست رایگان** | یک‌بار: ۱ روزه، ۵۰۰ مگ، پرسرعت‌ترین سرور؛ انقضای خودکار |
| 🔗 **ساب چندکانفیگه** | ~۱۰ سرور در هر ساب + کرون سلامت سرورها و جایگزینی خودکار سرور مرده |
| 🔳 **QR برند** | سرمه‌ای/طلایی + لوگوی سکه وسط + فریم — PNG کاملاً سرورلس |
| 🎮 **مینی‌اپ سکه‌ای** | تپ با انیمیشن، سطوح Bronze/Silver/Gold/Diamond، آپگرید، چرخ شانس روزانه، لیگ هفتگی با جایزه، ماموریت روزانه، فروشگاه سکه‌ای |
| 🤖 **چت هوش مصنوعی** | ۵ سکه هر پیام + تاریخچه کوتاه (Groq) |
| 📢 **گروه‌ها** | ثبت خودکار، خوش‌آمد عضو جدید، پست تبلیغی زمان‌بندی‌شده با نرخ لحظه‌ای و دکمه «🛒 خرید در پیوی»، پست فوری دستی |
| ⏰ **یادآوری** | قبل از انقضا + تمدید سریع + تخفیف کاربر غیرفعال |
| 💵 **قیمت‌گذاری هوشمند** | نرخ دلار از API + کش ۱۵ دقیقه‌ای + مارجین و نرخ دستی از پنل |

## ⚙️ متغیرها (داخل `wrangler.toml`)

| نام | وضعیت | توضیح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ پر شده | توکن ربات — طبق درخواست داخل کانفیگ دیپلوی |
| `GROQ_API_KEY` | اختیاری | چت AI + بررسی هوشمند فیش (رایگان از console.groq.com) |
| `WORKER_URL` | اختیاری | اگر خالی بماند، خودکار از اولین درخواست ذخیره می‌شود |

## 🕐 کرون‌جاب

هر ۱۵ دقیقه: کش نرخ ارز (رفرش کامل هر ۴ ساعت)، تست سلامت سرورها (هر ۶ ساعت) + جایگزینی خودکار سرور مرده، یادآوری انقضا، پست تبلیغی گروه‌ها، پرداخت جایزه لیگ هفتگی.

```
├── admin.js      # پنل مدیریت کامل با سطوح دسترسی
├── pay.js        # سفارش/کیف‌پول/کارت/تحویل/پاداش رفرال
├── verify.js     # بررسی فیش با بینایی Groq
├── subs.js       # ساب چندکانفیگه + جایگزینی سرور مرده + لندینگ
├── qr.js         # QR برند (انکودر PNG سرورلس)
├── game.js       # API و صفحه مینی‌اپ سکه‌ای (WebApp)
├── group.js      # خوش‌آمد گروه + پست تبلیغ زمان‌بندی‌شده
├── jobs.js       # کرون‌جاب‌ها
├── pricing.js    # نرخ لحظه‌ای + مارجین + کش
└── logo.js       # لوگوی بات (بیس۶)
```

## 🔐 نکته امنیتی

توکن بات هم در چت و هم (طبق درخواست شما) در `wrangler.toml` بوده/هست؛ چون ریپازیتوری عمومی است، **اکیداً توصیه می‌شود** بعد از دیپلوی از BotFather با `/revoke` توکن جدید بگیرید و با `wrangler secret put` ثبت کنید.
