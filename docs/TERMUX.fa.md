# ترموکس نُوا — کنسول مالک و سلف شخصی

دو ابزار مستقل وجود دارد. **کنسول مالک** Bot API را از طریق ورکر شما کنترل می‌کند و به ورود حساب Telegram نیاز ندارد. **سلف محلی** فقط برای حساب شخصی خودتان، با Telethon روی دستگاه خودتان است.

## ۱. کنسول مالک

```bash
pkg update
pkg install python git
git clone --branch arena/01a07081-aminck-nova-edge --single-branch \
  https://github.com/amingangmanatgh2-hash/AMINCK-Nova-Edge.git nova-guard
cd nova-guard
python termux/console.py
```

1. بات باید قبلاً روی Cloudflare Deploy شده باشد؛ توکن را در پنل وب در «ثبت و اتصال بات» وارد و اتصال خودکار را کامل کرده باشید.
2. با یکی از دو حساب مالک در خصوصی بات «ترموکس» یا `/terminal` بفرستید.
3. آدرس **اصلی HTTPS ورکر خودتان**، بدون مسیر یا query را در ترموکس وارد کنید. آدرس‌های ناشناس قابل‌اعتماد نیستند؛ کد اتصال دسترسی مدیریتی می‌دهد.
4. کد اتصال ۳۲ کاراکتری را از بات در ترموکس وارد کنید. کد ۱۰ دقیقه معتبر و یک‌بارمصرف است.
5. گزینه‌های بعد از اجرا:

| گزینه | کارکرد |
|---|---|
| ۱ | آمار و صف ربات |
| ۲ | فهرست گروه‌ها |
| ۳ | ارسال پیام از طرف بات، با پیش‌نمایش و تأیید |
| ۴ | ارسال و سنجاق |
| ۵ | روشن/خاموش کردن قفل محتوا |
| ۶ | پاک‌سازی تأییددار تا ۵۰۰۰ پیام ثبت‌شده |
| ۷ | افزودن الماس به کاربر دیده‌شده |
| ۸ | زمان‌بندی یک پیام |
| ۹ | آخرین رویدادها |
| ۱۰ | تنظیم وبهوک ورکر؛ وبهوک قبلی جابه‌جا می‌شود |
| ۱۱ | اجرای سلف محلی اختیاری |
| ۱۲ | ابطال همین مجوز کنسول و حذف فایل محلی مجوز |
| ۰ | خروج بدون ابطال مجوز |

عملیات بیرونی تأیید دقیق `YES` می‌خواهد. خطای شبکه، ارسال را خودکار تکرار نمی‌کند؛ ممکن است پیام قبلاً رسیده باشد.

اجرای مستقیم:

```bash
python termux/console.py status
python termux/console.py groups
python termux/console.py send --chat -1001234567890 --text 'سلام رفقا' --pin
python termux/console.py setup
```

`setup` یک اتصال تازه می‌گیرد. `--help` بدون اتصال شبکه راهنمای فرمان را نشان می‌دهد.

## ۲. سلف اختیاری فقط روی حساب خودتان

```bash
pip install -r termux/requirements.txt
python termux/self_client.py
```

### ورود امن

- API ID و API HASH را **خودتان و مستقیم** از `https://my.telegram.org` بگیرید. این‌ها با BOT_TOKEN فرق دارند.
- شمارهٔ حساب خودتان با کد کشور، کد ورود ارسال‌شده توسط Telegram و رمز دومرحله‌ای در صورت فعال‌بودن را **فقط در ترموکس خودتان** وارد کنید.
- برنامه از اتصال رسمی MTProto کتابخانهٔ Telethon برای ورود به Telegram استفاده می‌کند. هیچ‌یک از این مقادیر یا فایل session به ورکر، ربات نُوا یا شخص دیگری فرستاده نمی‌شود.
- با همان حسابِ واردشده، در خصوصی نُوا «سلف» بفرستید. فقط کد اتصال جداگانهٔ نُوا و شناسهٔ عددی حساب به API ورکر فرستاده می‌شود.
- سرور کد اتصال را به همان شناسه محدود می‌کند. کد یک حساب برای حساب دیگر کار نمی‌کند.
- تا زمانی که `YES` برای اجاره و تمدید ندهید، امکانات سلف شروع نمی‌شود.

### هزینه و توقف

- هر ساعت **شروع‌شده** ۵ الماس پیش‌پرداخت است؛ مالک‌ها (`8882866473` و `7856615968`) معاف‌اند.
- کنترل اعتبار هر ۶۰ ثانیه است؛ درخواست‌های تکراری در یک ساعت دوباره هزینه ندارند.
- با پایان ساعت، اگر برنامه باز باشد و موجودی کافی باشد، ساعت تازه خودکار رزرو می‌شود. کمبود اعتبار، ابطال مجوز یا ناموفق‌بودن بررسی شبکه، برنامهٔ رسمی را قطع می‌کند.
- سرور زمان روشن‌بودن گوشی را حدس نمی‌زند و خودش بدون درخواست کلاینت، ساعت تازه نمی‌فروشد. یک lease فعال به معنی آنلاین‌بودن قطعی حساب نیست.
- Ctrl+C ارتباط محلی را قطع می‌کند. زمان باقیماندهٔ ساعت پرداخت‌شده تا انقضای خودش باقی می‌ماند، ولی پول/الماسِ ساعت ناقص بازپرداخت نمی‌شود.
- «توقف سلف» در بات یا ابطال از پنل، مجوز و اجاره را حذف می‌کند؛ قطع کلاینت هنگام بررسی بعدی است، نه تضمین آنی شبکه.
- پس از انقضا/ابطال مجوز ۳۰روزه، کد تازه بگیرید و اجرا کنید:

```bash
python termux/self_client.py --pair
```

این گزینه **فقط مجوز نُوا را جایگزین می‌کند** و نشست Telegram دستگاه را نگه می‌دارد.

### فرمان‌های سلف

فقط روی **پیام‌های خروجی خود صاحب حساب** و با نقطه اجرا می‌شوند:

| فرمان | کارکرد |
|---|---|
| `.help` | راهنمای محلی |
| `.ping` | پاسخ‌گویی فرایند محلی |
| `.id` | شناسهٔ خود، گفت‌وگو و فرستندهٔ پیام ریپلای |
| `.time` | زمان UTC |
| `.calc (12+3)*2` | ماشین حساب با parser امن، بدون eval |
| `.afk دلیل` | پاسخ خصوصی دور از دسترس |
| `.back` | خاموش‌کردن AFK |
| `.autoreply on` / `off` | روشن/خاموش‌کردن پاسخ خصوصی |
| `.autoreply text سلام، بعداً جواب می‌دهم` | متن پاسخ خصوصی |
| `.save` با ریپلای | فوروارد همان پیام به Saved Messages، اگر Telegram اجازه دهد |
| `.note متن` | یادداشت در Saved Messages |
| `.clean 10 confirm` | حذف حداکثر ۵۰ پیام اخیر **خودتان**، در پنجرهٔ بررسی ۵۰۰ پیام |
| `.bold متن` | تبدیل همان پیام به متن ضخیم |
| `.italic متن` | تبدیل همان پیام به متن کج |
| `.code متن` | قالب کد |
| `.reverse متن` | برعکس‌کردن رشتهٔ متن |
| `.remind 5 متن` | یک یادآوری در Saved Messages پس از ۵ دقیقه |
| `.status` | وضعیت مجوز، AFK و پاسخ خودکار |

پاسخ خصوصی پیش‌فرض خاموش است؛ به بات‌ها و حساب سرویس Telegram پاسخ نمی‌دهد و برای هر شخص به یک پاسخ در ۳۰ دقیقه محدود است. یادآوری‌ها فقط تا وقتی همین فرایند باز و دارای مجوز است کار می‌کنند؛ حداکثر ۵ یادآوری هم‌زمان، ۱ تا ۱۴۴۰ دقیقه. زمان‌بندی پایدار پیام گروه، در ربات ورکر و دستور «زمانبندی» جداگانه وجود دارد.

### محل فایل‌ها و امنیت

```text
~/.nova-guard/
  terminal.json    مجوز کنسول مالک؛ ۳۰ روز
  self.json        مجوز اجارهٔ سلف؛ ۳۰ روز
  account.json     API ID و API HASH حساب شما
  account.session نشست MTProto محلی Telethon
```

پوشه با دسترسی `700` و فایل تنظیمات با `600` ساخته می‌شود؛ `umask 077` برای فایل‌های نشست فعال است. سیستم‌عامل یا دستگاه روت‌شده همچنان می‌تواند داده‌های شما را بخواند؛ این جایگزین امنیت خود گوشی نیست.

- فایل session **معادل کلید ورود حساب** است. آن را آپلود، در گیت ثبت یا برای پشتیبانی ارسال نکنید.
- برای قطع کامل نشست Telegram از **Settings → Devices** تلگرام، همان نشست را Terminate کنید. «توقف سلف» در نُوا این کار را انجام نمی‌دهد.
- پیام‌های دریافتی و کدهای Telegram در خروجی کنسول ثبت نمی‌شوند. خروجی خطا نام نوع خطا را نشان می‌دهد، نه محتوای پیام یا کلید نشست.
- کلاینت متن‌باز یک قفل اجارهٔ غیرقابل‌دورزدن نیست. پروتکل برای حسابداری نسخهٔ رسمی است، نه DRM یک برنامهٔ تغییریافته.
- از قابلیت‌ها فقط روی حساب خودتان و مطابق مقررات Telegram استفاده کنید. این نسخه ارسال انبوه، استخراج فهرست اعضا یا ابزار سرقت حساب ندارد.

### روشن‌ماندن در Android

Android می‌تواند برنامه‌های پس‌زمینه را ببندد. در صورت نیاز و آگاهی از مصرف باتری، محدودیت باتری ترموکس را تنظیم و در محیط دارای Termux:API از `termux-wake-lock` استفاده کنید. روشن‌ماندن دائمی تضمین نمی‌شود. سلف روی Cloudflare اجرا نمی‌شود؛ بستن ترموکس، خاموشی گوشی یا قطع شبکه آن را متوقف می‌کند.
