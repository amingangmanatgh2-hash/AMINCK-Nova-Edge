# SELF — سلف جدا از بات و اپ

سلف کاملا جدا از بات و اپ هست، ولی با یه ورکر ران میشه.

## اتصال به ربات

- فقط از طریق بات فعال میشه
- داخل پیوی ربات بزن: `سلف`
- یه کد ۳۲ کاراکتری یکبار مصرف میگیری
- اون کد رو داخل سلف وارد میکنی
- نشست تلگرام فقط روی دستگاه خودت میمونه، هرگز به سرور نمیره

## نصب و اجرا

```bash
pip install -r requirements.txt

# اکانت اول
python self_client.py

# اکانت دوم (نامحدود)
python self_client.py --session my2

# فقط توکن ربات رو عوض کن، نشست تلگرام بمونه
python self_client.py --pair
```

## قابلیت‌ها (۵۰+ دستور)

**پایه:**
- `.help` راهنما
- `.ping` وضعیت
- `.id` شناسه
- `.status` وضعیت مجوز و الماس

**متن:**
- `.font متن` فونت ساز ۷ استایل
- `.bold .italic .code .reverse`

**مخاطبین هوشمند:**
- `.contacts [فیلتر]` لیست ۵۰ تایی
- `.filter نام` جستجو
- `.find @username`
- `.add @username` تکی امن
- `.addall confirm` → `.addall YES` با تاخیر ۳ ثانیه ضداسپم سقف ۵۰

**گروه:**
- `.stats .admins .invite .pin .unpin`
- `.kick .ban .mute .tagall`

**هوش مصنوعی:**
- `.ai سوال` محلی + ابری اختیاری (کلید فقط محلی)
- `.chat on/off`

**دانلودر:**
- `.dl لینک` دانلود از یوتیوب/اینستا/توییتر
- `.ytdl لینک`

**کانفیگ ساز:**
- `.config` ساخت کانفیگ VLESS/VMess/Trojan/Shadowsocks
- `.proxy` لیست پروکسی
- `.vless .vmess .ss`

**ابزار:**
- `.weather .qr .tr .remind`
