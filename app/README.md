# APP — DemGram جدا از بات و سلف

اپ کاملا جدا از بات و سلف هست، ولی با یه ورکر ران میشه.

## اتصال به ربات

- فقط از ربات دانلود میشه
- داخل پیوی ربات بزن: `demgram` یا `دانلود` یا `اپ`
- لینک دانلود مستقیم: `/demgram/DemGram.apk`
- نسخه وب PWA: `/demgram/` — قابل نصب به عنوان APK

## قابلیت‌ها (جدا از سلف)

### 📥 دانلودر خفن
- یوتیوب (ویدیو/صدا)
- اینستاگرام (پست/استوری/ریلز)
- تیک‌تاک بدون واترمارک
- توییتر/X
- تلگرام فایل بزرگ

### 🔐 کانفیگ ساز خفن
- VLESS با Reality
- VMess
- Shadowsocks
- Trojan
- ساب لینک ساز base64
- پروکسی MTProto — لیست، تست سرعت
- QR کد برای کانفیگ‌ها

### 🛠 ابزار
- فونت ساز ۷ استایل
- ترجمه، QR، آب‌وهوا

### 💬 تلگرام کلاینت جدا
- چند اکانت نامحدود
- مدیریت مخاطبین هوشمند
- مدیریت گروه

## نصب

**PWA (فوری):**
1. `/demgram/` با کروم اندروید باز کن
2. منو → Add to Home Screen / نصب
3. حالا مثل APK بومی توی لیست برنامه‌ها میاد

**APK بومی:**
```bash
cd app/android
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

یا از ربات دانلود کن: `/demgram/DemGram.apk`

## تفاوت با سلف

- **سلف جدا**: حساب تلگرام خودت رو مدیریت می‌کنه — نیاز به API ID/HASH — از بات فعال میشه
- **اپ جدا**: کلاینت + دانلودر + کانفیگ ساز — از بات دانلود میشه
- **بات جدا**: مدیریت گروه‌ها — روی ورکر

هر سه جدا ولی یه ورکر.


## ⚠️ مهم: اپ سلف نیست!

- **اپ جدا**: کلاینت + دانلودر + کانفیگ ساز — از بات دانلود میشه — `app/` و `public/demgram/`
- **سلف جدا**: حساب شخصی — از بات فعال میشه — `self/self_client.py`
- **بات جدا**: مدیریت گروه — روی ورکر

سه تا جدا، یه ورکر. اپ رو سلف نکن!
